# CTF writeups

Mapping existing blue-team skills (forensics, network/PCAP analysis, OSINT) onto CTF categories — offense-side practice to sharpen the same detection instincts from the other direction.

## Path

OverTheWire Bandit → picoCTF → TryHackMe CTF rooms → HackTheBox → CTFtime.org

## Folders

- `bandit/` — Linux fundamentals, permissions, basic exploitation
- `picoCTF/` — broader category practice (forensics, crypto, web, reversing)

Each writeup: challenge summary, approach, what didn't work first, final solution. Same "show the mistake" philosophy as the incident tickets.
